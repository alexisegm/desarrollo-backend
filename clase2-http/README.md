# Clase 2: Diseño y Refactorización de APIs HTTP

Este repositorio contiene la resolución de las prácticas de backend enfocadas en el diseño, análisis y refactorización de APIs RESTFUL, manejando correctamente los métodos y códigos de estado HTTP.

## Estructura del Proyecto

El proyecto está dividido en dos fases principales:

1. **API Lite (`/lite-api`)**: 
   - Análisis de una API defectuosa preexistente.
   - Refactorización de endpoints en Express (corrección de verbos en rutas, validación de cuerpos de petición `400 Bad Request`, manejo de recursos inexistentes `404 Not Found` y estados de creación `201 Created`).
   - Documentación de análisis y comparativa (`lite-analysis.md`, `comparison.md`, `ai-usage.md`).

2. **API Full**: 
   - Construcción y diagnóstico de un sistema de solicitudes de mantenimiento a partir de un template base.
   - Definición de especificaciones técnicas (specs) y diseño estructurado sin el uso de ORMs ni arquitecturas sobre-complejas.

## Tecnologías
* Node.js
* Express.js
* Git & GitHub (Historial documentado usando Conventional Commits)
